# ReviewTrail scope

ReviewTrail packages the upstream code-review experience for local use in Claude Code and Pi.

- Use the upstream diff viewer and its chapter-based guided review for staged and unstaged changes, commits, patch files and pull requests.
- Keep line comments, feedback and forge submission under the reviewer’s control.
- Use the ReviewTrail executable, slash command, data directory and browser preferences so the fork can run alongside Plannotator.
- Export locally downloadable, self-contained HTML guides. Keep upstream telemetry, starring prompts and hosted guide publication out of the review build.
